Přehled autora

Chráněný přehled odeslaných dat. Klíč zůstává jen v paměti této stránky; nesdílej ho s účastníky.

Chybějící části se počítají za dokončené dny vybraného období od přihlášení k účasti. Neodeslané zápisy server nevidí. Ráno označuje noc následující po datu řádku. Přehled není živý snímek – pro nové odpovědi načti stránku znovu.

Jak získám klíč správce?

Jako vlastník projektu otevři Supabase → SQL Editor a spusť:

select research_token from public.mindtrack_push_config where id = 1;

Výsledek vlož pouze do pole nahoře. Nejde o veřejný API klíč.
