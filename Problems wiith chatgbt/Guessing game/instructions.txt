**Project 4: Guess the number**

Build a game where the player tries to guess a secret number between **1 and 20**.

**Requirements:**

- Show instructions, a number input, and a “Guess” button.
- Start with a fixed secret number of your choice.
- After each guess, display “Too high,” “Too low,” or “Correct!”
- Count valid guesses and display the total.
- Reject empty inputs and numbers outside 1–20 without counting them.
- Add a “Play again” button that resets the attempts, input, and feedback.
- Design the page yourself using your existing HTML/CSS skills.

**New concepts:** Reading an input’s `.value`, converting text to a number, and branching with `if`, `else if`, and `else`. Ask about these when you need them.

**Optional bonus:** Generate a random secret number for each game.

**Success criteria:** With the secret set to 12, guesses of 8, 16, and 12 produce the appropriate feedback and a total of three attempts. Invalid inputs don’t increase the count, and restarting clears the game.

Build the HTML and CSS first, then attempt the JavaScript. Send your work whenever you want a review or hint.
